# Results

- `key_results.json` — headline numbers reported in the manuscript.
- `figure_data/` — CSV nodes and edges for Figure 1 and numerical data for Figures 2–4.

Raw run directories (`summary.json`, `rows.json`, adapters) are not included
because they contain per-example generations and model checkpoints. Running the
scripts in `scripts/` reproduces them under `runs/`.
